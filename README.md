# Network Engineering Practice Labs Portfolio

Welcome to my Network Engineering showcase repository! This collection contains **46 hands-on practice labs** conducted using **Huawei eNSP (Enterprise Network Simulation Platform)**. This portfolio demonstrates a comprehensive range of networking skills, from core switching and routing to advanced firewall security and wireless implementations.

## 🚀 Repository Structure

The labs are organized into 6 core technology pillars, containing a total of 46 distinct projects:

### 1. [01-Fundamentals](./01-Fundamentals) (1 Lab)
- **VRP Basics**: Initial device configuration and CLI navigation on Huawei's Versatile Routing Platform.

### 2. [02-Switching](./02-Switching) (10 Labs)
- **Core Concepts**: VLANs, Trunking, and VLAN isolation.
- **Redundancy & Performance**: STP/RSTP implementation and Eth-Trunk (Link Aggregation).
- **Inter-VLAN Routing**: Router-on-a-Stick and Layer 3 switching.
- **Protocol Analysis**: GVRP configuration and behavior analysis.

### 3. [03-Routing](./03-Routing) (8 Labs)
- **Static Routing**: Advanced scenarios including floating static routes.
- **Dynamic Routing (OSPF)**: Single-area and multi-area OSPF design.
- **WAN Technologies**: PPP/Serial configurations and Frame-Relay.

### 4. [04-Network-Security](./04-Network-Security) (22 Labs)
- **Firewall Mastery**: Security zones, granular policies, and HRP (High Availability).
- **NAT Techniques**: Source NAT (SNAT), Destination NAT (NAT Server), Bidirectional NAT, and EasyIP.
- **Traffic & Access Control**: ACL filtering, Bandwidth management, Quotas, and AAA authentication.
- **Integrated Services**: OSPF over Firewalls and DHCP/NAT combined scenarios.

### 5. [05-Network-Services](./05-Network-Services) (3 Labs)
- **Core Infrastructure**: DHCP server, client, and relay configurations.
- **Application Services**: FTP and basic Web service simulation (NAT Server).

### 6. [06-WLAN](./06-WLAN) (2 Labs)
- **Wireless Networking**: Basic WLAN setup and a comprehensive Open-Ended Design Lab.

## 🛠️ Tools Used
- **Simulator**: Huawei eNSP
- **Operating System**: Huawei VRP (Versatile Routing Platform)
*   **Documentation**: Markdown, Topology Screenshots

## 📖 How to Use This Repo
1.  **Topology Files**: Each lab folder contains a `.topo` file that can be opened in Huawei eNSP.
2.  **Configurations**: Device configurations are stored within UUID-named subfolders to maintain full eNSP compatibility.
3.  **Visuals**: View `topology.png` or screenshots in each folder for a quick look at the network design.
